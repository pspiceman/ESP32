시작하는 방법

  1. MP4 불러오기에서 영상을 선택합니다. 인터넷이나 외부 라이브러리 없이 이 기기에서 처리합니다.
  2. 초록 당구대 테두리와 세 공 표시를 확인합니다. 제공 영상 구도를 기본값으로 넣었습니다. 각도가 다르면 안쪽 모서리 네 점을 다시 지정합니다.
  3. 색이 비슷한 두 공은 정지 화면에서 각각 번호를 한번 지정하면 위치 기준 추적이 안정적입니다. 공을 놓치면 1·2·3번 공 지정 버튼을 누르고 해당 공 중심을 터치합니다. 잘 보이는 정지 장면에서 지정하세요.
  4. 2인 경기 · 선수별 수구에서 1P는 1번 공, 2P는 2번 공을 기본으로 연결합니다. 반대라면 설정을 바꿉니다. 실제로 타격된 수구를 인식해 해당 선수를 기록하며, 무득점이면 상대 선수 차례를 예상합니다.
  5. 전체 분석 시작을 누르면 영상을 연속 재생하면서 득점을 계산합니다. 스페이스바 또는 분석 일시정지로 멈추고 다시 진행합니다. 느린 순차 모드는 제거했습니다. 프레임 누락 수를 확인하고 필요한 샷만 재검토하세요.
  6. 샷 기록의 보기로 영상을 확인한 뒤 득점 확정 / 무득점 확정을 선택합니다. 기본 모드의 득점은 자동 점수에 반영되며, 수동 변경이 우선합니다.
  7. 효과음: 첨부하신 딩동댕.mp3(득점)와 땡.mp3(무득점)가 HTML에 내장돼 자동 재생됩니다. 점수판의 효과음 설정에서 미리듣기·음원 변경을 할 수 있고, 첨부 MP3로 복원도 가능합니다.

첨부 rule.txt를 판정 기준으로 적용했습니다. 두 목적구를 처음 모두 맞힌 순간의 쿠션 횟수를 고정하며, 같은 목적구를 반복해 맞혀도 두 공을 맞힌 것으로 보지 않습니다. 프레임 사이 공 접촉을 놓치면 목적구가 가까운 거리에서 실제로 움직이기 시작했는지도 검사합니다. 이 근거로 추정된 접촉은 접촉 목록에 별도 표기합니다. 접촉 근거가 부족하면 자동 득점하지 않고 확인 필요로 표시합니다. 세 공의 정지 후 최종 판정하며, 정지 전에 영상이 끝나거나 분석을 중지하면 확인 필요입니다.

v3.9에서는 기기 처리 여유가 충분하고 프레임 누락이 없을 때만 진행 중 수구 궤적을 자동 표시합니다. 부하가 올라가면 즉시 숨겨 점수 판정을 우선하며, 샷 판정 종료 후에는 궤적을 지웁니다. 점수·샷·접촉 기록과 JSON의 좌표 데이터는 유지됩니다.

명세의 V=0은 영상 좌표 흔들림을 감안한 노이즈 허용값으로 구현했습니다. 각도 최솟값 10°와 정지 확인 1.15초는 영상 판독용 초깃값이며 보정 설정에서 변경할 수 있습니다.

다른 MP4와 색상 보정

같은 카메라면 영역·색상 설정을 유지할 수 있습니다. 색이 달라지면 해당 공만 다시 지정하세요. ‘보정 설정 저장’은 같은 브라우저에 저장하며, 설정 JSON 파일을 다른 기기로 옮길 수도 있습니다. 비슷한 색 공은 세 공을 동시에 경로 배정하여 추적합니다. 완전히 겹친 공은 번호 교환 가능성이 있어 수동 확인이 필요합니다.

영상이 재생되지 않을 때

MP4의 비디오 코덱을 브라우저가 지원하지 않으면 열리지 않습니다. 함께 제공한 billiards_sample_H264.mp4로 먼저 시험하세요. 원본은 HEVC이고 시험 파일은 H.264 변환본입니다.

판정 범위와 한계

수구의 쿠션·목적구 접촉 순서를 색상·위치·속도 변화로 추정합니다. 첫 목적구 이전 쿠션과 같은 쿠션에 다시 맞은 것도 포함합니다. 두 번째 목적구에 처음 닿기 전 세 쿠션 이상인지 확인합니다. 첨부 rule.txt에 따라 관측된 중심 거리가 1.05 × 공 지름 이하이면 접촉을 기록합니다. 프레임 사이 공의 이동 구간에서 중심 거리가 충분히 가까우며 전후 이동 흐름이 맞으면 기본 모드에서 접촉으로 계산합니다. 자동 결과는 실제 물리적 접촉을 보증하지 않습니다.

손·큐대 가림, 빠른 미세 접촉, 잘못된 영역·공 크기, 비슷한 공 색상, 장면 전환, 저프레임·프레임 누락은 오판 원인입니다. 모든 누락을 자동 검출하지는 못하므로 ‘실패 추정’도 영상으로 확인하세요. 수구 자동 선택도 틀릴 수 있습니다.

자동 분석은 브라우저가 제공하는 재생 프레임을 사용합니다. 원본의 모든 프레임을 읽거나 모든 접촉을 찾는것을 보장하지 않습니다. 기기의 디코딩 성능이 부족한 경우 영상 자체도 끊길 수 있습니다. 실시간 CCTV/RTSP 입력은 포함하지 않았습니다.

2인 경기 모드에서 1P·2P의 수구를 연결하고, 득점 시 같은 선수·무득점 시 교대를 예상합니다. 실제 타격 수구가 예상과 다른 경우 인식된 수구를 우선합니다. 확인 필요 장면은 차례 예상이 보류됩니다. 다른 영상을 열거나 설정을 바꾸면 이전 기록이 초기화됩니다. 샷 기록은 자동 영구 저장되지 않으므로 닫기 전 CSV 또는 JSON으로 저장하세요.
