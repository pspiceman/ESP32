일매출 = 선불차감액 + 입금액. 월회비와 선불 충전은 결제 기록과 따로 관리하며, 월매출에는 월회비가 더해집니다(선불 충전액은 사용할 때 매출로 잡힘).

1개월 연장을 누르면 시작일·종료일이 한 달씩 자동으로 늘어납니다. 월회원은 종료를 누르기 전까지는 종료일이 지나도 수금 대상이 아닙니다(퇴실 때 금액 입력 없음).

입금일과 금액을 입력하면 잔액이 쌓이고, 퇴실 때 잔액만큼 자동으로 선불 차감되며 모자라는 금액만 수금합니다.
