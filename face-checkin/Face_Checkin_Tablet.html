회원 관리 (0명)

회원번호는 Q001부터 자동 부여됩니다. 재등록 권장 표시는 이전 버전(2.x)에서 등록된 얼굴입니다. 정확도를 위해 얼굴 재등록을 눌러 다시 촬영해 주세요.

실행 방법 · 정확도 안내

HTTPS 주소(GitHub Pages 등)를 태블릿 Chrome에서 열거나 홈 화면에 설치해 사용하세요. 첫 실행 때 카메라 권한을 한 번 허용하면 이후 자동으로 켜집니다.

사용 순서: 똑똑 → 정면 바라보기(1~2초) → "OOO님 환영합니다". 잘못 인식되면 "제가 아니에요"를 누르세요. 처음 오신 분은 이름 입력 창이 자동으로 열리고, 이름만 입력하면 등록됩니다.

정확도: 등록 때 정면 8장, 확인 때 4장을 평균하고, 두 눈이 수평이 되도록 얼굴을 정렬한 뒤 비교합니다. 1순위와 2순위 차이가 작으면 자동으로 환영하지 않고 비슷한 분들만 골라 보여 줍니다. 어두우면 화면 가장자리를 흰색으로 밝혀 조명을 보조합니다.

얼굴 분석은 기기에서만 수행하며 사진·영상을 저장하거나 서버로 보내지 않습니다(얼굴 특징값 숫자만 이 기기에 저장). 생체 위조(사진) 검출 기능은 없습니다.
