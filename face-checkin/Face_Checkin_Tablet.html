인식 설정

엔진 상태 확인 중…

고정밀 엔진은 처음 한 번 모델(약 39MB)을 받아 기기에 저장합니다. 기존 회원은 다음 입장 때 고정밀 데이터가 자동으로 추가되며, 그 전까지는 기본 엔진 값으로 비교합니다. 모델을 받지 못하면 자동으로 기본 엔진으로 동작합니다.

최근 판정 기록 (기준값 조정용)

본인 거리(통과 시)와 다른 가족 거리 차이가 작으면 판정 기준을 엄격으로, 본인이 자주 실패하면 관대로 바꾸거나 얼굴을 다시 등록하세요.

원격 관리 (퍼블릭 MQTT)

원격 관리 꺼짐

관리자 웹: Face_Checkin_Tablet_admin.html · 같은 브로커 · 매장 코드 · 암호 키를 넣으면 입실 현황을 보고 결제 확인 후 퇴실을 처리할 수 있습니다. 퍼블릭 브로커는 누구나 접속할 수 있으므로 회원 정보는 암호 키로 AES-GCM 암호화해서 보냅니다(얼굴 특징값은 보내지 않음). 암호 키를 비우면 암호화 없이 전송되니 꼭 설정하세요.

입장 알림 (ntfy)

알림 꺼짐

신규 등록·입장이 생기면 ntfy로 알림을 보냅니다. 관리자 웹(또는 휴대폰 ntfy 앱)에서 같은 서버·토픽을 구독하면 바로 표시됩니다. 구독 주소: —
ntfy.sh 공개 서버는 토픽 이름을 아는 사람이면 누구나 볼 수 있으므로 "토픽 자동 생성"으로 추측하기 어려운 이름을 쓰세요. 알림에는 이름·회원번호·핸디·입실 시각만 들어가며 전화번호·얼굴 정보는 보내지 않습니다.

회원 관리 (0명)

회원번호는 Q001부터 자동 부여됩니다. 재등록 권장 표시는 이전 버전(2.x)에서 등록된 얼굴입니다. 정보 수정으로 이름·핸디·전화번호를, 얼굴 재등록으로 얼굴을 바꿀 수 있습니다.

전체 화면

"화면 새로고침"·아래로 당기기는 페이지를 다시 열지 않아 전체 화면이 그대로 유지됩니다. 페이지를 새로 열 때(최신 버전 새로고침·재부팅 등)는 브라우저 규칙상 "화면을 터치해 주세요" 시작 화면을 한 번 터치하면 전체 화면이 됩니다. 항상 주소창 없이 쓰려면 Chrome 메뉴 ⋮ → 홈 화면에 추가로 아이콘을 만들어 실행하세요.

새로고침 · 업데이트

GitHub에 새 파일을 올리면 5분 안에 자동으로 확인해 새 버전으로 바뀝니다(손님이 쓰는 중에는 끝난 뒤 적용). 바로 바꾸려면 입장 화면을 아래로 길게 당겼다 놓거나 "최신 버전으로 새로고침"을 누르세요. 회원·입실 기록·설정은 그대로 유지됩니다. GitHub Pages 반영에는 올린 뒤 1~2분이 걸릴 수 있습니다.

설정 잠금

⚙ 설정은 항상 비밀번호로 잠겨 있습니다. 기본 비밀번호는 0000이니 설치 후 꼭 바꿔 주세요.

실행 방법 · 정확도 안내

HTTPS 주소(GitHub Pages 등)를 태블릿 Chrome에서 가로로 열어 사용하세요. 첫 실행 때 카메라 권한을 한 번 허용하면 이후 자동으로 켜집니다.
사용 순서: 톡 → 정면 바라보기(1~2초) → "OOO님 입장 확인". 퇴실은 관리자가 결제 확인 후 관리자 웹에서 처리합니다.
처음 왔어요: 얼굴을 약 2초 촬영 → 인식되면 얼굴로 등록, 인식이 안 되면(마스크 등) "전화번호 입력으로 등록 가능합니다" 안내 후 사진만으로 등록합니다. 이후 이름/닉네임 → 핸디 → 휴대폰 번호 입력은 같습니다.
번호로 입장: 회원인데 얼굴 인식이 안 되면(마스크·역광 등) 휴대폰 뒷자리 4자리로 입장합니다. 같은 번호가 여러 명이면 이름을 고릅니다. 번호 입장은 관리자 웹 기록에 "번호"로 표시됩니다.
정확도: 등록 때 정면 8장, 확인 때 4장을 평균하고 두 눈이 수평이 되도록 정렬한 뒤 비교합니다. 1·2순위 차이가 작으면 비슷한 분들만 골라 보여 줍니다.
얼굴 분석은 기기에서만 수행하며 사진·영상을 저장하거나 보내지 않습니다(얼굴 특징값 숫자만 이 기기에 저장). 생체 위조(사진) 검출 기능은 없습니다.
