등록된 회원

회원번호는 Q001부터 자동 부여됩니다. 체크 기록은 하루 단위로 초기화됩니다. 전체 삭제 시 번호가 Q001부터 다시 시작합니다.

실행 방법 · 상시 운영 안내

이 파일을 GitHub Pages 등 HTTPS 주소에 올려 태블릿 Chrome에서 여세요. 첫 실행 때 카메라 권한을 한 번 허용하면 이후에는 페이지를 열 때마다 카메라가 자동으로 켜집니다.

상시 운영: 화면 꺼짐 방지(Wake Lock)를 자동 요청하고, 카메라가 끊기거나 인식이 멈추면 자동으로 다시 시작합니다. 매일 새벽 4시경 페이지를 자동 새로고침합니다(등록 창이 열려 있으면 미룸).

Chrome 정책상 음성 안내는 화면을 한 번 터치해야 켜질 수 있습니다. 전원을 연결한 상태로 두고, 태블릿의 화면 고정(앱 고정) 기능을 함께 쓰면 좋습니다.

얼굴 분석은 기기에서 수행하며 사진·영상·얼굴 특징값을 서버로 전송하지 않습니다. 브라우저 데이터를 삭제하면 회원 정보와 체크 기록도 삭제됩니다. 생체 위조(사진) 검출 기능은 없습니다.
