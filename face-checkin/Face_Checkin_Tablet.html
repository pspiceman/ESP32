처음 사용하시나요? 실행 방법과 저장 안내
  1. 이 HTML 파일을 HTTPS 웹 서버에 올리고 안드로이드 태블릿 Chrome에서 해당 주소를 여세요. 다운로드 파일 미리보기나 일반 HTTP의 PC 내부 IP 주소에서는 카메라가 제한될 수 있습니다.
  2. 인터넷에 연결한 뒤 ‘카메라 시작’을 누르고 카메라 권한을 허용하세요. 최초 모델 로딩에는 시간이 걸릴 수 있습니다.
  3. ‘신규 등록’에서 이름·회원번호를 입력하고 동의 확인 후 얼굴을 등록하세요.
  4. ‘회원 입장’에서 기존 회원이 카메라를 바라보면 입장 정보가 자동 표시됩니다.

회원 정보와 얼굴 특징값, 입장 기록은 이 브라우저의 IndexedDB에만 저장합니다. 얼굴 사진과 영상은 저장하거나 서버로 전송하지 않습니다. 인식 라이브러리와 모델은 외부 CDN에서 내려받습니다. 브라우저 데이터 삭제·다른 기기·다른 사이트 주소에서는 등록 정보가 유지되거나 공유되지 않습니다. 별도 백업 기능은 없습니다.

현재 버전은 동작 확인용입니다. 사진·영상 위조를 막는 생체 확인, 관리자 인증, 암호화 저장, 서버 동기화 기능은 포함되지 않습니다. 잠금 장치나 결제 인증에는 사용하지 마세요. 실제 회원으로 인식 정확도를 확인한 뒤 사용 범위를 정하세요.

얼굴 매칭 기준: 거리 0.48 이하, 2위 회원과 거리 차이 0.07 이상, 연속 3회 일치. 거리는 확률이 아닙니다. 등록 시 유사 얼굴이 있으면 중복 등록을 차단합니다.
