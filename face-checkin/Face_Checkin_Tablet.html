실행 방법 · 테스트 범위

이 파일을 GitHub Pages에 올려 생성된 https://…github.io/… 주소를 태블릿 Chrome에서 여세요. 첫 화면으로 사용하려면 파일 이름을 index.html로 변경해 업로드하면 됩니다. 다운로드 파일의 content:// 주소에서는 카메라가 차단될 수 있습니다.

카메라 요청이 거부되면 태블릿 설정의 Chrome 카메라 권한과 해당 사이트의 카메라 권한을 확인하세요. 카메라 권한은 HTML 코드로 강제로 허용할 수 없습니다.

인식 라이브러리와 모델은 인터넷에서 내려받습니다. 얼굴 분석은 기기에서 수행하며 이 코드에는 사진·영상·얼굴 특징값을 서버로 전송하는 기능이 없습니다. 브라우저 데이터 삭제 시 등록 정보도 삭제됩니다.

얼굴 인식 테스트 전용입니다. 입장 기록·관리자 비밀번호·백업·서버 연동·문 제어·생체 위조 검출 기능은 포함하지 않습니다.
